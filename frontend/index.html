🖥 Instalador Windows — CyberSec Gateway

v0.1.0 · x64 · Windows 10/11

El instalador MSI despliega cybersec-gateway.exe como un servicio Windows con inicio automático. Incluye pantalla informativa para usuario final y modo avanzado para administradores.

✔ Servicio Windows autostart ✔ Variables de entorno del sistema ✔ Modo admin SHOW_ADVANCED=1 ✔ API Keys opcionales ✔ Acceso directo en menú Inicio
Instalación estándar:
msiexec /i cybersec-gateway.msi
Modo administrador (con API Keys):
msiexec /i cybersec-gateway.msi SHOW_ADVANCED=1
Instalación silenciosa (CI/CD):
msiexec /i cybersec-gateway.msi ABUSEIPDB_API_KEY=xxx /qn
🔧 Para generar el .msi: compilar con cargo build --release y luego ejecutar packages/windows/generate_gateway_msi.ps1
